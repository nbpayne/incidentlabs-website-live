Engineering

Guesswork, replaced with measurement.

Resolve’s native tools are powerful but often approximate — a drag, a slider, a feel. Every Incident Labs tool works the other way: explicit parameters, documented behaviour, and results that reproduce exactly, tool to tool and project to project.

01

Native to the pipeline

DCTLs run inside Resolve's node graph at full GPU speed — no plugin host, no round-trip. Scripts run from Resolve's own console or your terminal. Nothing external to install or babysit.

02

Every control, documented

Parameters are expressed in units you already think in — stops, percentages, fixed points — with a defined range and behaviour. A setting means the same thing on every clip, every machine, every year.

03

Built for the whole project

Tools are tested against heavy node stacks and full-length timelines, not single demo clips — so a look that holds on shot one still holds on shot four hundred.

04

One-time purchase, lifetime updates

No subscriptions, no recurring licence checks. Buy once, and every future update to that tool is yours.

05

Built by a working colourist

Every tool starts as a fix for a real problem on a real grade, not a spec sheet. If it ships, it's because it earned its place in someone's actual workflow.

06

Documented, and a real person to ask

Every product ships with full documentation covering setup and every control. Still stuck? Email goes to the team directly — most replies land within one business day.
